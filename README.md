# أبطال الأزهر — تطبيق ويب (PWA)

تطبيق قابل للتثبيت على موبايل الأولاد: أيقونة على الشاشة الرئيسية، يفتح بملء الشاشة زي أي تطبيق، وبيشتغل **بدون إنترنت** بعد أول فتح.

## الملفات
- `index.html` شاشة البداية واختيار الصف
- `grade1.html` حتى `grade6.html` لعبة كل صف — الأول ٢٥٠، الثاني ٣٠٠، الثالث ٤٠٠، الرابع ٥٠٠، الخامس ٤٥٠، السادس ٦٠٠ (الإجمالي ٢٥٠٠ سؤال)
- `manifest.webmanifest` + `sw.js` ملفات التطبيق (التثبيت والعمل أوفلاين)
- الأيقونات بكل المقاسات ومنها نسخة Maskable لأندرويد

## شرط التثبيت الوحيد
الـPWA لازم يتنشر على رابط HTTPS (أي استضافة ملفات ثابتة مجانية تنفع: GitHub Pages أو Netlify Drop أو Cloudflare Pages) — ارفع كل الملفات زي ما هي في مكان واحد.

## تثبيت الأولاد للتطبيق
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق» ← هتظهر أيقونة «أبطال الأزهر» على الشاشة الرئيسية.
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- بعد التثبيت بيشتغل أوفلاين بالكامل، وتقدم كل طفل بيتحفظ على جهازه.
